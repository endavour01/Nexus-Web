# NEXUS Website

A cinematic HTML/CSS/JavaScript prototype based on the five-panel NEXUS concept board: cinematic landing, interactive three-mode showcase, NEXUS System, ecosystem, and cinematic feature story.

## Run

```bash
cd nexus-website
python3 -m http.server 4173
```

Open http://localhost:4173

The site is intentionally dependency-light. The mode switcher changes the live browser mockup and uses the Default/Balanced/Performance emblem assets.
